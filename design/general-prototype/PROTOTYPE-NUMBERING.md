# Нумерация прототипа (reviewer-only)

**Актуальная модель — книжная:** один целый номер на логический экран-шаблон (`1…152` на ветке book2). Полная таблица: **`PROTOTYPE-PAGES.md`**.

Файлы: `prototype-numbering.js`, `prototype-numbering.css` в корне `design/general-prototype/`. Подключение в HTML: `?v=book2`.

Корень хаба выводится из `document.currentScript.src` (файл лежит в корне прототипа), без угадывания `../` по глубине — вложенный hosted-префикс (`/unique-id/…`) поддерживается в TOC и `pathnameRel`.

На экране: «Страница N · краткое название» и кнопка «Страницы» (поиск + оглавление со ссылками). Маркеры на кнопках/блоках **убраны**.

Каталог зашит в `prototype-numbering.js` (`window.PROTOTYPE_PAGE_CATALOG`). Новые экраны добавляйте в конец, не перенумеровывайте.

## Устаревшая схема (до book1)

Раньше использовался формат `3.x.x` с бейджами на каждом элементе. Ниже — архивное описание.

## UI (устар.)

- **Номера: вкл/выкл** — маркеры на элементе (default: вкл).
- **Список номеров** — поиск, клик → подсветка и прокрутка, копирование номера.
- **Скопировать индекс** — весь список текущего экрана (буфер / скрытое поле).
- Печать/PDF: слой скрыт (`@media print`).
- Не трогает `textContent` продукта, `pointer-events: none` на слое (кроме кнопок ревью и маркеров для копирования).
- `MutationObserver` — новые dialog/шаги SPA пересчитываются.
- Нет `localStorage` / fetch / сервера; состояние только в памяти вкладки.
- Реестр: `window.__protoNumRegistry` (ref, label, stableKey, pageState, location); поиск элемента: `window.__protoNumResolve(ref)` или атрибут `data-proto-number` на целевом узле.
- Самотесты: `node design/general-prototype/prototype-numbering.selftest.mjs`, `stability.mjs`, `overlap.mjs`, `browser.mjs` (localhost + hosted prefix).

## Ограничения

- Плотные экраны: уменьшенные маркеры + обязателен индекс.
- Не нумеруются вложенные узлы внутри уже пронумерованной кнопки/ссылки; `label[for]` при парном `input`.
- Декоративные обёртки без смысла могут не получить отдельный номер; секции, карточки, контролы, строки таблиц — да.
