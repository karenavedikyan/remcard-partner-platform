# Нумерация элементов прототипа (reviewer-only)

Файлы: `prototype-numbering.js`, `prototype-numbering.css` в корне `design/general-prototype/`.

## Пространства имён (первая цифра номера)

| Цифра | Зона |
| --- | --- |
| **1** | Общий вход (`index.html`) |
| **2** | Клиентский сайт (`client/…`) |
| **3** | Кабинет партнёра (`partner/…`) |
| **4** | Кабинет администратора (`admin/…`) |

Формат номера: **`{ns}.{page4}.{elem5}`** (например `3.1842.12837`).  
Второй блок — хэш **страницы + состояния** (файл, роль, релиз R1/R2, активный раздел, hash, открытый dialog).  
Третий — хэш **семантического ключа** элемента (`id`, `data-testid`, `data-action`, `name`, `aria-label`, стабильный путь).

Один и тот же экран после перезагрузки даёт те же номера; смена роли/раздела/R2 — другой `page4`, номера не смешиваются между экранами.

## Покрытие HTML (15)

`index.html`, `client/index.html`, `admin/index.html`, все `partner/*.html` (13 страниц partner). Версия подключения: `?v=ann3`.

При открытом нативном `<dialog showModal>` (кроме UI нумерации) панель, хром и маркеры поднимаются в top layer через `popover="manual"`, чтобы оставаться поверх модалки без перехвата фокуса продукта.

Клиент/админ в репозитории — минимальные оболочки для hash-маршрутов и пространств 2/4; полный SPA остаётся в артефакте сборки.

## UI

- **Номера: вкл/выкл** — маркеры на элементе (default: вкл).
- **Список номеров** — поиск, клик → подсветка и прокрутка, копирование номера.
- **Скопировать индекс** — весь список текущего экрана (буфер / скрытое поле).
- Печать/PDF: слой скрыт (`@media print`).
- Не трогает `textContent` продукта, `pointer-events: none` на слое (кроме кнопок ревью и маркеров для копирования).
- `MutationObserver` — новые dialog/шаги SPA пересчитываются.
- Нет `localStorage` / fetch / сервера; состояние только в памяти вкладки.
- Реестр: `window.__protoNumRegistry` (ref, label, stableKey, pageState, location); поиск элемента: `window.__protoNumResolve(ref)` или атрибут `data-proto-number` на целевом узле.
- Самотест ключей: `node prototype-numbering.selftest.mjs`.

## Ограничения

- Плотные экраны: уменьшенные маркеры + обязателен индекс.
- Не нумеруются вложенные узлы внутри уже пронумерованной кнопки/ссылки; `label[for]` при парном `input`.
- Декоративные обёртки без смысла могут не получить отдельный номер; секции, карточки, контролы, строки таблиц — да.
