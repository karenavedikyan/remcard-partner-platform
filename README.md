# RemCard Partner Platform

Отдельный кабинет RemCard. Первый выпуск: дизайн утверждённого прототипа и существующий функционал программы PROF основного сайта. Новые возможности добавляются после запуска.

## Начало работы в Cursor

Первое задание: [M1: основа проекта и подключение существующего PROF](docs/tasks/M1.md). Выполнять только этот этап; переход к следующим задачам и публикация согласуются отдельно.

После частичного выполнения M1 используйте [M1: снятие блокеров и проверка прокси](docs/tasks/M1-unblock.md). M2 не начинается до проверки подключения; существующий каркас не нужно создавать повторно.

Текущая проверка продолжения: [M1: результат проверки и тестовый backend](docs/reviews/M1-2026-10-06.md).

Скопируйте в Cursor:

```text
Прочитай docs/tasks/M1.md и выполни только задание M1.
Работай в этом репозитории. Основной RemCard пока только изучай.
Не изменяй production, не создавай платные ресурсы и не публикуй сайт.
В конце покажи выполненные проверки, изменения и блокеры, затем остановись.
```

## Границы первого выпуска

- Разработка ведётся в этом отдельном репозитории.
- Дизайн берётся из утверждённого прототипа, функционал из действующего RemCard.
- На первом этапе доступны только существующие сценарии PROF.
- Целевой адрес кабинета: `pro.remcard.ru`. Приложение в этом репозитории пока не реализовано и не опубликовано.
- Репозиторий публичный: не добавлять секреты, рабочие `.env`, персональные данные, дампы БД и закрытые материалы.
