# P149 Variant A — визуальный handoff (UI only)

## Внешние поля партнёра («Поля партнёра» в фильтрах)

- Редактирование значений — **только в карточке обращения** (`externalRefs` на detail GET/PATCH).
- Отдельного **аддитивного справочника** полей (как `manualChannels` для источников) в текущем K1 **нет**; кнопка в списке **disabled** (раньше был только toast) и **не открывает настройку**.
- Новые POST/kinds и расширение прав **не вводились** в этом раунде.

## КП

- Compose: `1 из 2 · Черновик`, preview: `2 из 2 · Проверка`, заголовок предпросмотра «Как увидит клиент».
- Отправка остаётся по `commercialProposal.sendEnabled`; при `false` — пояснение в footer (backend не трогался).

## Drawer

- Footer «Отменить / Сохранить» закреплён у **нижнего края** side panel, не внутри прокрутки lifecycle.
- Ответственный: без ввода raw user id; назначение через PATCH `responsibleUserId` только при появлении безопасного staff-read (сейчас — отображение + поля в карточке).
