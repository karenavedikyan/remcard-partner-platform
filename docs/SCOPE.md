# Границы первого выпуска (M1 → релиз)

Дата: 6 октября 2026 года.

## Включено в первый выпуск (после M1)

Только существующие пользовательские сценарии PROF основного сайта RemCard:

| Область | Сценарии |
| --- | --- |
| Аккаунт | вход, регистрация, обязательный профиль, выход |
| Партнёры | поиск, приглашение, список |
| Условия | действующие условия сотрудничества и их согласование |
| Сертификаты / QR | выдача, список, публичная карточка, ссылка, PDF |
| Покупка | сканирование или ручной ввод, просмотр условий, покупка |
| Финансы | доступная история и начисления (только через backend RemCard) |

## Выполнено в M1

- Минимальный каркас Next.js 14 в `remcard-partner-platform`.
- Дизайн-токены из утверждённого прототипа (`pro.remcard.ru`).
- Серверный BFF-прокси `/api/remcard/*` для безопасного обращения к backend.
- Технический стартовый экран без фиктивных балансов и финансовых действий.
- Документация: `REUSE-MAP.md`, `STATUS.md`, `SCOPE.md`.

## Отложено (backlog)

Не реализовывать до отдельного согласования:

- Новые проценты, шаблоны условий, массовые приглашения.
- CRM, аналитика, альтернативные способы подтверждения выплат.
- Второй кошелёк, финансовый журнал, дублирование пользователей.
- Функции, видимые в прототипе, но отсутствующие в рабочем backend.
- Демо-данные и frontend-расчёты прототипа как бизнес-логика.
- Экраны PROF (кроме технического старта M1).
- Автоматические cron, уведомления, реальные покупки и выплаты.

## Ограничения

- Backend: `remcard.ru` (единая БД и пользователи).
- Целевой адрес кабинета: `pro.remcard.ru` (DNS не меняется в M1).
- Основной репозиторий `remcard-navigator` в M1 не изменяется.
- Репозиторий публичный: без секретов, дампов и персональных данных.
