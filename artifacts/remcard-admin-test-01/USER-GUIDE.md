# Инструкция владельцу: тестовые партнёры на prof.remcard.ru

1. Попросите оператора включить флаги **только на нужном стенде** и выполнить миграцию (см. MIGRATION-AND-RELEASE.md).
2. Оператор создаёт пароль администратора:  
   `tsx scripts/prof-admin-bootstrap-credential.ts --user=<staffAdminId> --apply`  
   (пароль вводится скрыто, не в git).
3. Откройте **https://prof.remcard.ru/login** → вкладка **«Вход администратора»** → логин и пароль.
4. Перейдите в **«Тестовые пользователи»** (`/admin/test-users`).
5. **Создать** → выберите тип (агент, специалист, магазин, компания) и имя (например «Тест · Агент 1»).
6. **Открыть ЛК** → заполните профиль как обычный партнёр; данные сохраняются после обновления страницы.
7. **Вернуться в управление тестами** — жёлтая панель «Тестовый режим» или кнопка на панели.
8. **Сбросить профиль** — очищает черновик/поля агента и UI prefs (реквизиты не удаляются без отдельного подтверждения в UI).

Ограничения: тестовый пользователь не входит по MAX/Telegram сам; не отправляет реальные уведомления и платежи; не виден в публичном каталоге. Для двух аккаунтов одновременно используйте **два профиля браузера** (разные cookie).
