# R04 — кратко для владельца

1. Включите `PROF_R04_AGENT_PARTNERS_ENABLED=true` на staging после миграции `PartnershipListPreference`.
2. Войдите в **тестовый ЛК агента** (управление тестами → «Открыть ЛК»). Завершите профиль агента, если R04 не появился.
3. Откройте **Партнёры**: сверху «Действующие» / «Приглашения»; кнопки «Найти в RemCard» и «Пригласить по ссылке».
4. Проверьте список (без 401), поиск с фильтрами, alias/архив (локально), приглашение test↔test.
5. Для смены стороны вернитесь в **Управление тестами** и откройте ЛК контрагента.
6. Production gate не включать до приёмки визуального parity-набора.
